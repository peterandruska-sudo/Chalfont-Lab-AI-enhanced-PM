How to Build Your Own Agent and Upload a RAID Log
1. Review the Agent Instructions

Carefully read the provided instructions section.
Understand the agent’s purpose, guidelines, skills, and workflow.

2. Customize Instructions for Your Scenario

Update the Purpose, Guidelines, and Skills to match your business needs.
Modify any step-by-step workflows or examples to align with your processes.

3. Prepare Your RAID Log

Ensure your RAID log (Risks, Assumptions, Issues, Dependencies) is saved in a supported format (e.g., Excel, Word, PDF).
Store the file in a location accessible to Microsoft 365 Copilot, such as SharePoint or OneDrive.

4. Create a New Agent in Copilot Studio

Go to Microsoft 365 Copilot Studio.
Start a new agent project.

5. Add Instructions

Paste the customized instructions into the agent’s Instructions field.
Adjust for tone, process, and organization as needed.

6. Add Your RAID Log as a Knowledge Source

In the Configure or Knowledge section, add the SharePoint or OneDrive URL where your RAID log is stored.
This lets your agent reference and answer questions using your RAID log.
Make sure you use the direct URL starting with https (not just a file name).

7. Complete Agent Properties

Enter a clear name and description for your agent.
(Optional) Add conversation starters to help users get started.

8. Save and Test Your Agent

Save your agent draft.
Use the Test chat to ensure the agent can retrieve and answer questions based on your RAID log.

9. Create and Share

When ready, click Create to publish your agent.
Share it within your organization or export the manifest to GitHub.
